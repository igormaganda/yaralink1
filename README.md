# YaraLink — parcours client

Landing page B2B en français, centrée sur le point de vue client.

## Aperçu local

```bash
python3 -m http.server 8000
```

Ouvrir `http://localhost:8000`. Le site est statique et ne requiert aucune compilation.

## Publication

Pour GitHub Pages, publier la branche `main` depuis la racine `/`. Les chemins des ressources sont relatifs pour fonctionner sous une URL de projet GitHub Pages.

Les liens de contact et d’intégrations pointent vers `yaralink.tech` ; vérifier leurs destinations avant diffusion commerciale.
